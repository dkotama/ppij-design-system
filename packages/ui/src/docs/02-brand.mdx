# Brand

- **Name**: PPIJ, Persatuan Pelajar Indonesia di Jepang
- **Primary color**: PPIJ red, `#C8102E`
- **Type**: Plus Jakarta Sans, with Noto Sans JP for Japanese text
- **Icons**: Tabler icons only. Never use a text glyph as an icon.
- **Language switch**: a quiet text action or a labelled menu. Never isolated
  boxed EN or ID codes as a primary button.
- **Typography law**: admin typography equals portal typography. Same
  families, same scale.

The logo file and the full usage rules live in the `brand/` folder of the
repository. Token values on the Colors page are the binding values.
