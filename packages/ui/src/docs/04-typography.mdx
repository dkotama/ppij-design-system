Font stack: **Plus Jakarta Sans**, **Noto Sans JP**, system-ui, sans-serif.
One stack serves the public site, the portal, and admin.

Rules: never introduce a second font family; never set type in a component
with a raw pixel value when a scale step exists; long words and long Japanese
or Indonesian strings must wrap without breaking the layout.

## Vertical rhythm and spacing

Type breathes on a 4px base scale. Steps: **4, 8, 12, 16, 24, 32, 48**.

- Body text: 16px, line height 1.6. Paragraphs are separated by **16px**, never by an empty line in markup.
- Headings: line height 1.25. Space above a heading is **24px** (32px for a page title), space below is **8px**, so a heading visibly belongs to the text that follows it.
- Supporting text under a heading or a label above a field: **6 to 8px**.
- Inside a card: 16px between blocks, 24px on desktop. Inside a form: 6px label to field, 16px field to field.
