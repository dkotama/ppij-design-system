text glyph as an icon, and never mix in a second icon family.

## Usage rules

- Size: 16px inside buttons and badges, 20px in lists, 24px as a standalone
  action. Keep one size step per surface.
- Stroke: 1.8 by default, matching the Tabler outline style.
- Color: inherit the text color (`currentColor`). Never hard code an icon
  color outside a token.
- Meaning: an icon supports a label, it does not replace it, except for
  familiar toolbar actions that carry an accessible name.
- In components, icons arrive as children or props, as the Button and Badge
  stories show. A component never imports a page-specific icon set.
