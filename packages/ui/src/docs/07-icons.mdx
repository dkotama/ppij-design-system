# Icons

One icon family only: **Tabler Icons** (`@tabler/icons-react`). Never use a
text glyph as an icon, and never mix in a second icon family. Pick icons
from the curated set below first; reach for another Tabler icon only when
none of these carries the meaning.

export const cell = { border: "1px solid #e3e5e8", borderRadius: 10, padding: 12, background: "#fff", textAlign: "center" };
export const grid = { display: "grid", gridTemplateColumns: "repeat(auto-fill, minmax(132px, 1fr))", gap: 10 };
export const cap = { fontSize: 11, marginTop: 8, color: "#5b6168" };

      <div key={name} style={cell}>
        <Icon size={24} stroke={1.8} />
        <div style={cap}>{name}</div>
      </div>
    ))}
  </div>
);

## Usage rules

- Size: 16px inside buttons and badges, 20px in lists and navigation,
  24px as a standalone action. Keep one size step per surface.
- Stroke: 1.8 by default, matching the Tabler outline style.
- Color: inherit the text color (`currentColor`). Never hard code an icon
  color outside a token.
- Meaning: an icon supports a label, it does not replace it, except for
  familiar toolbar actions that carry an accessible name.
- In components, icons arrive as children or props, as the Button and Badge
  stories show. A component never imports a page-specific icon set.
